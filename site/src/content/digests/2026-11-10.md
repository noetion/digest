Today’s stories cover new frontier and small-footprint models from Anthropic and Meta, a critical Claude Code settings leak that exposed secrets on GitHub, Bytedance’s production-focused Seedream 5.5 image model, and Meta FAIR’s e-means k-means replacement. Each story has concrete availability, pricing, or repo milestones engineers can inspect.

## Anthropic releases Claude Fable 5.2 and Mythos 5.2, claiming faster generation, higher benchmark scores, and priced tiers

- **What happened:** Anthropic announced Claude Fable 5.2 and Mythos 5.2, the same underlying model with Fable shipping broadly and Mythos gated via Life Sciences and Cyber Verification Programs. Anthropic reports up to 30% faster generation versus Fable/Mythos 5.1, optional fast mode up to 2.5x faster, and list pricing of $8 per million input tokens and $40 per million output tokens, with fast mode priced at $16 per million input and $80 per million output.
- **Why it matters:** Anthropic’s published internal benchmarks show Fable/Mythos 5.2 ahead of Opus 5.5 on a broad set of agentic coding, scientific, cybersecurity, and multimodal tests, and the company positions Fable/Mythos for high-effort, open-ended technical tasks while recommending Opus 5.5 as the daily driver. The combination of higher capability, lower quoted token costs, and a fast-mode pricing tier changes cost/performance trade-offs for engineering tasks that need agentic chains, long-context multimodal inputs, or specialized cybersecurity and life-science workflows.
- **Outlook:** Read the Claude Fable 5.2 and Claude Mythos 5.2 System Card for full evaluation and safety details, the single public document Anthropic points to for deeper methodology and results.

## Meta publishes Muse Ember, a 1M-token, low-cost model tuned for agent execution and repetitive subtasks

- **What happened:** Meta released Muse Ember (muse-ember: 1.0) on Muse Code and the Meta Model API with a 1M-token context window, up to 512K output tokens, and list pricing of $0.10 per million input tokens and $0.50 per million output tokens (with $0.004 per million cached input tokens). Meta’s report cites internal and Artificial Analysis evaluations where Muse Ember leads in agent benchmarks and cost-per-task estimates.
- **Why it matters:** Muse Ember targets the high-volume, structured calls agents make, tool calls, extraction, file parsing, and small coding subtasks, and Meta’s published scores show it delivering higher agent throughput and better cost-per-task than the cited baselines at many reasoning settings; that positions Muse Ember as a cheaper execution-tier model for agent orchestration or for batching many small, structured requests.
- **Outlook:** Meta’s Muse Ember release references the November 9 Artificial Analysis evaluations as the published benchmarks; the next public checkpoints are any updates to the Artificial Analysis leaderboard and partner reports that reuse muse-ember: 1.0 in production agents.

## Claude Code settings files were committed to public GitHub repos, exposing thousands of secrets, Apiiro reports

- **What happened:** Apiiro researchers found over 100,000 instances of Claude Code local settings files on public GitHub repositories; roughly 1,100 files from 63 organizations contained secrets such as API tokens, database passwords, or private keys. The leak traces to how Claude Code records a user’s approved automated shell commands in .claude/settings.local.json, sometimes writing commands verbatim into the file, and repositories do not always inherit the global .gitignore that would exclude that file.
- **Why it matters:** Settings files that record a persistent "Yes, and don’t ask again" approval can contain sensitive command strings and may be automatically committed by Claude Code; once uploaded, sensitive values can persist in forks or clones even after removal. The flaw creates an immediate operational surface for credential exposure and post-incident forensic work for teams using Claude Code locally.
- **Outlook:** GitHub removals, secret rotations, and the presence or absence of patched Claude Code client behavior that stops writing secrets into settings.local.json will be the immediate public signals of remediation and residual exposure scope described in the Apiiro report.

## Bytedance rolls out Seedream 5.5 for production image editing with pixel-stable multi-round edits and native RGBA output

- **What happened:** Bytedance announced Seedream 5.5, which it says preserves unchanged image areas at the pixel level across up to 100 editing rounds without color drift, produces native RGBA images with transparent backgrounds, improves rendering of light/materials and dense small text, and is rolling out via Jimeng, Doubao, Doubao Work, and Volcengine Ark with a Pro version planned.
- **Why it matters:** Pixel-stable multi-round editing and native RGBA output reduce manual post-processing in iterative design and production workflows; Bytedance’s rollout across internal and cloud products and a planned Pro tier signals a vendor-targeted push to integrate model output directly into asset pipelines rather than relying on downstream cropping or masking.
- **Outlook:** The scheduled rollout to Jimeng, Doubao, Doubao Work, and Volcengine Ark and the planned Pro version are the vendor milestones to watch for broader availability and any feature or pricing differences between standard and Pro releases.

## Meta FAIR open-sources e-means, a k-means replacement that claims 10× fewer epochs and large wall-clock speedups

- **What happened:** Meta FAIR published e-means and its implementation (repo: faiss/contrib/e_means), describing an EMA-based centroid update, automatic scaling laws for batch and step size, a proportional cluster-revival policy, and validation across 24 datasets where e-means reaches Lloyd-level losses in 1.2–3 epochs versus 25 epochs for Lloyd.
- **Why it matters:** E-means replaces Lloyd’s full-pass updates with mini-batch EMA updates plus automatic hyperparameter scaling and a split-based dead-cluster revival, producing reported 10–45× GPU wall-clock speedups versus a Flash-KMeans baseline and 8–15× on CPU versus Faiss; that directly impacts large-scale clustering workflows used in embedding indexes, quantizers, and vector-search pipelines.
- **Outlook:** The faiss/contrib/e_means GitHub repository and its benchmark suite are the next concrete artifacts to inspect for reproductions, implementation details, and the end-to-end wall-clock comparisons Meta FAIR published.
