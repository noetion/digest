Today’s threads: OpenAI is rolling Chat and Work into a single usage meter and changed GPT-6.2 billing; Anthropic published a machine-checked GRH proof in Lean; Microsoft documents ARTEX-powered automated attacks and defensive deception; and DeepMind now lets agents control part of Gemini compute for experiments. All items affect engineers who run, verify, or defend production AI systems.

## OpenAI rolls Chat and Work into a single usage meter, limited rollout now and broader rollout planned in December

- **What happened:** OpenAI began rolling a unified Chat and Work experience to a small group of Pro subscribers; Chat and Work will share a single usage meter and Instant-model conversations remain unlimited. An OpenAI spokesperson said most users should not see more frequent resets but the heaviest users may hit limits sooner.
- **Why it matters:** Engineers and heavy model users will see combined quota accounting across chat and work flows, which can change effective access to advanced reasoning models even if Instant remains unlimited. The move reflects provider-level quota consolidation that can affect long-running or high-throughput automation and integration tests.
- **Outlook:** OpenAI plans to extend the shared usage limits more broadly in December, according to its support page.

## OpenAI fixes GPT-6.2 billing error, users now hit Astra 40% and Sol 25% faster versus last week

- **What happened:** OpenAI acknowledged a billing mistake that had incorrectly discounted GPT-6.2 Astra and Sol usage and said it fixed the error; after the fix, identical work will consume 40% more Astra usage and 25% more Sol usage compared with last week. OpenAI said it will not charge users retroactively for the difference and will add one banked reset for Go, Plus, Pro, and Business plans.
- **Why it matters:** Developers and SREs tracking quota consumption or forecasting costs must update usage models because effective token accounting for GPT-6.2 Astra and Sol increased by the stated percentages; the banked reset partially offsets near-term quota pressure but does not change ongoing higher consumption rates.
- **Outlook:** OpenAI will add one banked reset to Go, Plus, Pro, and Business accounts as an apology for the billing error, per the announcement.

## Anthropic publishes a machine-checked Lean 4 GRH proof repository under Apache 2.0

- **What happened:** A repository described as a Lean 4 proof of the Riemann Hypothesis and the Generalized Riemann Hypothesis for Dirichlet L-functions was published, based on Levent Alpöge’s work and produced with Claude; the artifact includes a readable edition (~300,000 lines) and a compact edition (~76,000 lines), requires Lean v4.35.0 and Mathlib at commit 56a00585, and the proofs have passed machine checks only.
- **Why it matters:** Engineers working on formal verification, reproducibility, or theorem-proving toolchains gain a large, machine-checked artifact they can build and inspect; the repository’s Apache 2.0 license and explicit build requirements let teams reproduce the machine checks if they provision the specified Lean and Mathlib versions and allocate roughly 1–2 hours on a 12-core, 24 GB machine for a build.
- **Outlook:** Building the repository with the required Lean v4.35.0 and Mathlib commit 56a00585, which takes about one to two hours on a 12-core machine according to the README, is the current public verification milestone for the artifact.

## Microsoft details ARTEX framework usage by state-backed and criminal groups and recommends deception-based defenses

- **What happened:** Microsoft Threat Intelligence described how the ARTEX AI framework automates attacks end-to-end by delegating reconnaissance, planning, and exploitation to specialized agents that run tools like Nmap, Sqlmap, Metasploit, and headless browsers; the report notes ARTEX can switch models or API keys on error, run multiple attack chains simultaneously, and operate at machine speed with bursts of traffic.
- **Why it matters:** Production defenders face attacker workflows that orchestrate existing tooling at machine speed and evade static indicators by rotating models, API keys, and network paths; Microsoft recommends active deception techniques, honeypots, tarpits, fake success signals, and strict access controls and rate limits as practical mitigations grounded in observed ARTEX behavior.
- **Outlook:** Microsoft’s Threat Intelligence report and its described telemetry, including observed bursts like 2,900 login attempts per minute in one campaign and 151,000 failed guesses in another, serve as the current public reference for defender countermeasures and alerts.

## DeepMind says AI agents now control part of compute for Gemini experiments, but not full recursive self-improvement

- **What happened:** DeepMind’s VP of Research Koray Kavukcuoglu said on the lab’s podcast that AI agents are given control of part of the compute to run experiments for the next Gemini model; he also said DeepMind does not reward agents’ chain-of-thought during training so internal reasoning stays reviewable and that recursive self-improvement remains distant.
- **Why it matters:** Engineers running model-training experiments should note that agents are being used to schedule or execute experiments on live compute for Gemini development and that DeepMind applies training safeguards such as not rewarding chain-of-thought, which affect how internal agent behavior is exposed and audited during experimentation.
- **Outlook:** Future Gemini-generation experiments will use agent-controlled compute as described by DeepMind for the next Gemini model; DeepMind frames each Gemini generation as a hand-built one-off with parallel teams working on successors.
