Today’s stories center on tooling, model capability, and infrastructure: OpenAI's Codex CLI now auto-starts a persistent self-updating daemon by default; a paper shows models can cryptographically hide capabilities; Meta released Muse Wonder as a frontier model with new memory features; Microsoft details a plan to scale Maia chips to multi-gigawatt deployment; and a Microsoft Research paper shows Fork-and-Flush improves long-running agent search.

## Codex CLI 0.157.0 starts a persistent self-updating background daemon by default, users call for opt-in

- **What happened:** Since Codex CLI 0.157.0, starting an interactive codex session launches a persistent background daemon (codex app-server --managed-daemon) that runs detached, copies a ~374 MB managed package into ~/.codex/packages/app-server-daemon/releases/<version>/, and starts an hourly updater that downloads and restarts the daemon. Users report the daemon persists after closing sessions and that stopping the daemon leaves the updater process running.
- **Why it matters:** A CLI that spawns a long-running, self-updating process decouples the runtime serving binary from the package-manager-managed CLI artifact and can pin inherited environment variables across sessions, changing security and operational assumptions for developers and sysadmins.
- **Outlook:** Repository issue discussion and commits referenced between Sep 25 and Oct 13, 2026, set an immediate forward signal: watch the GitHub issue tracker for an explicit change to make daemon_auto_start opt-in or documented config guidance in the Codex CLI repo (issues #48195 and linked updater/upstream issues).

## ArXiv paper shows AI models can provably hide arbitrary capabilities behind cryptographic triggers

- **What happened:** A paper submitted Oct 9, 2026 constructs backdoor attacks that embed encrypted neural networks in host weights, decrypting and executing them only on a secret trigger, and provides cryptographic hardness results showing the hidden circuits are hard to elicit or interpret even with full weight access; authors released proof-of-concept PyTorch implementations and evaluation on a small chemical reaction prediction task.
- **Why it matters:** The result undermines the assumption that capability evaluations can reliably surface all dangerous behaviors, because hidden encrypted subcircuits can remain undetectable to fine-tuning, weight noising, gradient-based trigger search, and latent adversarial training under the paper's cryptographic assumptions.
- **Outlook:** The paper release itself is the next milestone: its released models and code are the immediate public artifacts researchers can run to reproduce the claimed resistance to elicitation methods, so expect follow-up defenses and replication attempts on the provided repository and arXiv entry in the coming weeks.

## Meta releases Muse Wonder frontier models and says largest variant outperforms several competitors on benchmark suites

- **What happened:** Meta announced Muse Wonder and Muse Wonder Full as frontier-capability models and said the largest version outperforms Anthropic’s Claude Fable 5.1 and ranks below Claude Opus 5.5 on the Artificial Analysis Intelligence Index; Meta also claims Muse outperforms GPT-6 Astra and some Claude variants on specialized benchmarks for legal and software tasks, and will serve the models via API and Muse Code.
- **Why it matters:** A new frontier-model release from Meta with claimed benchmark gains and features named Active Memory and Active Focus aims to reduce agent confusion and keep models aligned to stated goals, which affects choices for teams selecting hosted frontier models for agentic or long-horizon software tasks.
- **Outlook:** Meta said Muse models will be available through an API and Muse Code and that their best version will power platform features; expect API availability and platform integration details and documentation releases from Meta following the announcement as the next public product milestones.

## Microsoft Research shows Fork-and-Flush context resets boost long-running agent performance by 66 percent on average

- **What happened:** Microsoft researchers evaluated 'Autoresearch' agents and found runs get trapped in low-performing 'idea basins'; their Fork-and-Flush method forks K parallel branches inheriting workspace files while flushes remove chat history, and on 13 tasks Fork-and-Flush raised normalized average score to 0.78 from 0.47 for single runs, a reported relative improvement of 66.0 percent.
- **Why it matters:** For agentic systems that iteratively propose and refine solutions, explicitly managing conversational context by forking workspaces and clearing chat state markedly increases search diversity and consistency, a practical systems-level control to improve long-horizon agent outcomes without changing model parameters.
- **Outlook:** The Decoder coverage cites experiments using GPT-5.6-terra and GPT-5.5; the next concrete signals will be public patch notes or code releases from the Microsoft Research authors and any accompanying datasets or replication packages that document the exact Fork-and-Flush protocol used on the 13 tasks.

<small>Sources: [the-decoder.com](https://the-decoder.com/clearing-chat-history-helps-ai-agents-find-better-solutions/)</small>

## Microsoft plans multi-gigawatt deployment of Maia AI chips, claims up to 1.7x tokens per watt on Maia 200 and 40 percent gains with Maia 300

- **What happened:** Microsoft plans to deploy Azure Maia chips at multi-gigawatt scale starting in 2027 and says Maia 200 already runs Copilot in the US, Europe, and Australia; Microsoft claims Maia 200 pushes up to 1.7 times more tokens per watt than leading GPUs in Teams, and that Maia 300 (shipping in 2027) targets 40 percent more tokens per megawatt than leading GPU systems and a 96-chip rack can produce up to seven times the tokens of a Maia 200 rack.
- **Why it matters:** Microsoft’s public plan to scale in-house Maia silicon to multi-gigawatt datacenter deployments changes procurement and performance assumptions for large-scale inference, since the company positions Maia as its main inference system across products and reports specific tokens-per-watt and rack-level throughput claims.
- **Outlook:** Microsoft said a technical report covers Maia details and that more information will appear at Ignite 2026 in November, making the Ignite presentation and any accompanying technical report the next concrete milestones for verification and implementation details.
